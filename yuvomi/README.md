# Yuvomi

![amd64][amd64-shield] ![aarch64][aarch64-shield]

The self-hosted family planner – tasks, calendar, shopping lists, meals,
budget, health and more – running on your Home Assistant.

- Opens in the sidebar
- Sign in with your Home Assistant users
- Included in Home Assistant backups
- Configured in the Home Assistant UI

See the **Documentation** tab for setup, options and backups.
